*lazyscion.txt*  hyperscion's `hs ui` in a floating terminal

==============================================================================
CONTENTS                                                    *lazyscion*

`hs ui` is hyperscion's lazygit-style terminal UI. lazyscion opens it in a
float, as lazygit.nvim does for lazygit.

==============================================================================
COMMANDS                                                    *:Lazyscion*

:Lazyscion          Toggle the float. The worktree is the nearest `.hs`,
                    looked up from the current file, then from the current
                    directory. Hiding keeps `hs ui` running; `q` inside it
                    quits and closes the float.

==============================================================================
SETUP                                                       *lazyscion.setup()*

>lua
    require('lazyscion').setup({
      cmd = { 'hs' },        -- `ui` is appended
      width = 0.9,           -- fraction of the editor
      height = 0.9,
      border = 'rounded',
      title = ' hyperscion ',
    })
<

==============================================================================
FUNCTIONS                                                   *lazyscion-api*

lazyscion.open()      Show the float (start `hs ui` if it isn't running).
lazyscion.hide()      Hide the float; `hs ui` keeps running.
lazyscion.toggle()    Open or hide.
lazyscion.close()     Close the float and drop `hs ui`'s buffer.
lazyscion.edit({path})
                      What `hs ui` calls (over --remote-expr) when you press
                      `e`: hides the float and edits {path}.

==============================================================================
KEYS (inside hs ui)                                         *lazyscion-keys*

  j k           move in a list
  h l tab 1-5   switch panels (Status, Files, Log, Review, Tasks)
  enter esc     scroll the main panel, and back
  J K ctrl-d/u  scroll the main panel from anywhere
  c P           land (asks for a message)
  A             ask for review instead of landing (pick reviewers)
  a x m         in Review: approve, request changes, comment
  n s S D X     in Tasks: new, start, stop, done, drop
  p             sync
  d             discard the selected file
  e             edit the selected file in this Neovim
  r             refresh
  ?             every key
  q             quit
